# Wedding + 

Application web intelligente de planification et de gestion de mariage.

## Stack cible

- Frontend : Vue.js + Vite
- Backend : Node.js + Express.js
- Base de données : MongoDB + Mongoose
- Authentification : JWT
- IA : intégration via API côté backend

## Structure prévue

```text
wedding-plus/
├── frontend/
└── backend/
```

## Fonctionnalités prévues

- Gestion du projet de mariage
- Tâches et planning
- Budget
- Prestataires
- Invités et RSVP
- Invitations
- Plan de table
- Documents
- Alertes
- Mode Jour J
- Plan B
- Assistant IA

> Projet en cours de développement. Les fonctionnalités réellement implémentées seront documentées au fur et à mesure.
